# Public Support Site

This folder is ready to upload to a static hosting service.

## Files

- `index.html`
- `support.html`
- `privacy-policy.html`
- `styles.css`

## URLs Needed For App Store Connect

After publishing, use:

- Support URL: `https://YOUR-DOMAIN/support.html`
- Privacy Policy URL: `https://YOUR-DOMAIN/privacy-policy.html`

## Easy Hosting Options

- Netlify Drop: drag the `public-site` folder into Netlify Drop.
- GitHub Pages: publish this folder from a repository.
- Cloudflare Pages: create a Pages project from a repository or direct upload.

## Required Before App Store Submission

- Confirm the published URLs are public HTTPS URLs.
- Confirm both pages open without login.
- Confirm the support email is `redsealapp@gmail.com`.
